# Yahya Sarkar — Portfolio Website

A responsive personal portfolio for an independent web developer. It presents selected concept work, services, an about page, and a project enquiry form, with lightweight CSS and JavaScript animations.

## Pages

- `home.html` — introduction and selected work
- `services.html` — services and project process
- `about.html` — approach and values
- `contact.html` — project enquiry form

The site uses plain HTML, CSS, and JavaScript. No build step or dependencies are required; open `home.html` in a browser to view it locally.
